# Логика отдельно от сети

Эксперимент вне JustMC. Идея: сеть не рассуждает. Она только переводит предложение в запись
(предикат и его аргументы), а всё, что является логикой, выполняет обычный код: он не может
ошибиться «чуть-чуть» и не требует данных.

```
предложение → переводчик (сеть) → запись → таблица фактов → правила (код) → ответ
```

## Этап 1: bAbI

| файл | что это |
| --- | --- |
| `engine.py` | таблица фактов и правила: где кто находится, кто что несёт, порядок во времени, «или — или», отрицание, вывод по виду, обобщение по примерам, транзитивные отношения, координаты, кратчайший путь. Ничего не обучается |
| `world.py` | генератор предложений с готовыми записями. Все имена, места и предметы — выдуманные слова |
| `translator.py` | переводчик: эмбеддинг → двунаправленный LSTM с ячейкой Millennium → роль каждого слова и предикат (attention-пулинг). 70 805 параметров |
| `babi.py` | прогон на официальных задачах bAbI |
| `translator.pt` | обученный переводчик |

Переводчик учится только на предложениях из `world.py` (несколько минут на процессоре) и ни одной
истории bAbI не видел. Слова, которые не являются служебными, для сети — одна из 64 безымянных
корзин, поэтому запомнить «Mary» или «kitchen» она не может: учится только строение фразы.
Аргументы записи — сами слова предложения, движок сравнивает их точно.

При разборе действует грамматика записей: у каждого предиката разрешены только его роли, запись
без обязательной роли не принимается.

### Результат

Официальный тест bAbI (20 задач по 1000 вопросов, английский): **19998 / 20000 = 99,99 %**.
19 задач — 100 %, задача 5 — 998 / 1000. На обучающей части те же цифры.

Два оставшихся вопроса задачи 5 — «What did Bill give to Mary?», когда Билл отдавал Мэри разные
предметы. Движок отвечает про последний раз; в данных обычно так же, но иногда ожидается более
ранний, и из текста это не определить.

```bash
python translator.py --out translator.pt
python babi.py --data tasks_1-20_v1-2/en --model translator.pt --split test
```

Данные: https://s3.amazonaws.com/text-datasets/babi_tasks_1-20_v1-2.tar.gz

### Что это показывает, а что нет

- Показывает: при таком разделении сети остаётся простая работа (строение фразы), и ей хватает
  70 тысяч параметров; логика при этом точная на любой длине истории.
- Не показывает понимания свободного текста. Язык bAbI шаблонный, шаблоны `world.py` написаны
  по нему, а правила движка — под эти 20 задач. Точный разбор bAbI программой давно известен;
  здесь это отправная точка, а не достижение.
- Два правила взяты из обучающей части bAbI, потому что сам текст их не задаёт: цвет нового
  животного — как у последнего представленного животного того же вида (задача 16), а на вопрос
  «куда пойдёт» при отсутствии примера в истории отвечает маленькая таблица знаний (задача 20).

Слабое место всей схемы — переводчик на живом, нешаблонном языке. Второй этап проверяет именно это.

## Этап 2: текстовые арифметические задачи (SVAMP)

Тексты здесь написаны людьми. Разделение то же: считает код, сеть только читает.

```
текст → все выражения над его числами, каждое посчитано точно (код) → сеть выбирает одно → ответ
```

| файл | что это |
| --- | --- |
| `calc.py` | перечисляет выражения до двух действий над числами текста и считает их точно, в дробях. Одинаковые по смыслу выражения, например (a + b) − c и a − (c − b), остаются в одном экземпляре: это проверяется вычислением на пробных значениях |
| `solver.py` | сеть, которая оценивает выражения, и её обучение |
| `mathworld.py` | микромир задач: генератор историй с вопросами |
| `solver.pt` | обученная сеть, 670 338 параметров |

Что делает точная часть:

1. **Перечисление и проверка.** Деление на ноль и неположительный результат отбрасываются до сети.
   Сеть не может ошибиться в счёте, она может только выбрать не то выражение.
2. **Точные метки.** То, что код знает наверняка, а маленькой сети пришлось бы угадывать по
   нескольким тысячам примеров: повторяется ли слово в вопросе; спрашивают ли про то, что считает
   это число; называет ли вопрос что-то, что стоит рядом с одними числами и не стоит рядом с
   другими; считают ли два числа одно и то же; целый ли получился результат.
3. **Обучение по ответам.** Разметка уравнениями не нужна: правильным считается любое
   перечисленное выражение, значение которого равно ответу.
4. **Лишние числа.** Из каждой обучающей задачи код делает копии с числом, которое не может влиять
   на ответ: фраза или предложение с числом повторяется с другим числом и с заменой слова, про
   которое спрашивают («14 kids on monday» → «… and 31 kids on friday», вопрос по-прежнему про
   monday). Ответ известен без разметки: он прежний.
5. **Микромир.** Генератор историй, где к одной истории задаются разные вопросы (сумма, разность,
   часть владельцев, «было — стало», «на сколько больше», равные группы, «каждый день»), и от
   вопроса меняется правильное выражение. В собранных задачах такого почти нет, а SVAMP проверяет
   именно это.

Сеть: эмбеддинг → двунаправленный LSTM с ячейкой Millennium → вектор числа (состояние на его месте)
→ вектор выражения, собранный снизу вверх маленьким слоем на каждое действие → оценка выражения
вместе с вопросом.

### Результат

Стандартные условия: обучение на MAWPS + ASDiv-A (3138 задач), тест — SVAMP (1000 задач, составлен
так, чтобы ломать модели, которые не читают вопрос). Обучение — около 15 минут на процессоре.
Через дробь — запуски с разным начальным состоянием.

| | SVAMP, % |
| --- | --- |
| *опубликовано:* Seq2Seq, с нуля | 24,2 |
| GTS, с нуля | 30,8 |
| Graph2Tree, с нуля | 36,5 |
| Graph2Tree + RoBERTa | 43,8 |
| DeductReasoner + RoBERTa | 47,3 |
| *здесь:* сеть и перечисление, без меток и фактов | 35,6 / 34,8 |
| + точные метки и факты | 39,6 / 40,0 |
| + лишние числа | 51,1 / 52,4 |
| + микромир | 56,4 / 57,3 / **59,4** |
| то же, но обучение по уравнениям, а не по ответам | 58,2 |

Сеть одна и та же во всех строках (0,67 млн параметров), обучающие задачи те же. Разницу между
35 % и 57–59 % дают только части, написанные кодом. Обучение по одним ответам не хуже обучения
по уравнениям. `solver.pt` — запуск с лучшим результатом на отложенной части обучающих задач
(SVAMP 59,4 %).

Опубликованные цифры: [SVAMP, табл. 10](https://aclanthology.org/2021.naacl-main.168.pdf) и
[сводная таблица](https://hyper.ai/en/sota/tasks/math-word-problem-solving/benchmark/math-word-problem-solving-on-svamp).

```bash
python solver.py --train train.csv --test dev.csv --world 2000 --out solver.pt
python solver.py --model solver.pt --ask "Tom had 12 apples. He ate 5 of them. How many apples does Tom have left?"
```

Данные: https://github.com/arkilpatel/SVAMP/tree/main/data/mawps-asdiv-a_svamp

### Оговорки

- Сравнение с опубликованными сетями не равное по входу: здесь сеть получает точные метки и видит
  факты о посчитанных значениях, там — только текст. В этом и состоит проверяемая идея, но это
  надо иметь в виду. Большие языковые модели решают SVAMP на 90 % и выше.
- Какие истории нужны микромиру, решалось по ошибкам на первых 200 задачах SVAMP. На остальных
  800, ошибки на которых не просматривались: 55,5 / 56,0 / 58,6 % (на первых 200: 60,0 / 62,5 / 62,5).
- Эпоха выбирается по отложенной десятой части обучающих задач, не по SVAMP.
- Выражение использует каждое число один раз и содержит не больше двух действий. 26 задач SVAMP
  требуют одно число дважды и поэтому недостижимы.
- На обучающем распределении (отложенная часть) точность 90–94 %. Разрыв с SVAMP — это понимание
  живых формулировок: шаблонный микромир переносится на них только частично.
